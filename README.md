# AI for Fraud Detection - Task 3

## 📌 Overview
This project implements a Machine Learning system to detect anomalies in financial transactions. It addresses the challenge of identifying fraudulent patterns in high-volume, imbalanced datasets.

## 🛠️ Features
- **Random Forest Classifier:** Utilizes ensemble learning for 95%+ detection accuracy.
- **Synthetic Data Generation:** Implements a custom data engine to simulate real-world financial fraud scenarios without compromising privacy.
- **Predictive Analysis:** Real-time flagging of "Normal" vs "Fraudulent" transactions.

## 🚀 Tech Stack
- Python
- Scikit-Learn
- Pandas & NumPy

## ⚙️ Installation
1. Install ML tools: `pip install pandas scikit-learn`
2. Run: `python fraud_detection.py`
