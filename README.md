# AI Chatbot Development - Task 1

## 📌 Overview
This project is part of my AI Internship at **Hex Softwares**. It features a professional-grade Virtual Agent built using the latest **Gemini 2.0 Flash** model and the new **google-genai SDK**.

## 🛠️ Features
- **Natural Language Processing (NLP):** High-accuracy intent recognition.
- **Modern SDK:** Implemented using the brand-new `google-genai` library (moving away from deprecated versions).
- **Context-Aware:** Designed to handle professional inquiries for Hex Softwares.

## 🚀 Tech Stack
- Python
- Google Gemini 2.0 Flash
- google-genai SDK

## ⚙️ Installation
1. Install dependencies: `pip install google-genai`
2. Run the bot: `python chatbot.py`
